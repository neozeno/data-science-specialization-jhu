Loop Functions

Writing for and while loops is useful when programming but not particularly easy when working interactively on the command line. There are some functions which implement looping in an easier way.

  • lapply: Loops over a list and evaluate a function on each element
  • sapply: Same as lapply but attempts to simplify the result
  • apply: Applies a function over the margins of an array
  • tapply: Applies a function over subsets of a vector
  • mapply: Multivariate version of lapply

split, an auxiliary function, is also useful, particularly in conjunction with lapply.

lapply

lapply take three arguments: (1) a list X, (2) a function (or the name of a function) FUN, and (3) other arguments via its ... argument. If X is not a list, it will be coerced to a list via as.list.

lapply
function (X, FUN, ...) 
{
    FUN <- match.fun(FUN)
    if (!is.vector(X) || is.object(X)) 
        X <- as.list(X)
    .Internal(lapply(X, FUN))
}
<bytecode: 0xb311484a0>
<environment: namespace:base>

The actual looping is done internally in C code.

lapply always returns a list, regardless of the class of the input.

In the following example, we iterate over the list x and apply the mean function to each of its two members. lapply() returns a new list with the mean of each of the items of x.

x <- list(a = 1.5, b = rnorm(10))
lapply(x, mean)
$a
[1] 1.5

$b
[1] -0.2397348

Similarly, we apply the mean function to a list y, which contains four elements.

y <- list(a = 1.4, b = rnorm(10), c = rnorm(20, 1), d = rnorm(100, 5))
lapply(y, mean)
$a
[1] 1.4

$b
[1] -0.3043549

$c
[1] 0.8780816

$d
[1] 4.962988

sapply

sapply is a variant of lapply. All it does is attempt to simplify the result of lapply, if possible.

  • If the result is a list where every element is of length 1, then it returs a vector
  • If the result is a list where every element is a vector of the same length (although > 1), then it returns a matrix
  • If it can’t figure things out, then it returns a list

Calling lapply(y, mean) before, returned a list of length 4, where every element of the list is a single number.

Calling, sapply() instead, returns a vector with four numbers.

sapply(y, mean)
         a          b          c          d 
 1.4000000 -0.3043549  0.8780816  4.9629883

apply

The apply() function is used to evaluate a function (often an anonymous one) over the margins of an array.

  • It is most often used to apply a function to the rows or columns of a matrix
  • It can be used with general arrays, e.g., taking the average of an array of matrices
  • It is not really faster than writing a loop, but it works in one line!

Syntax

str(apply)
function (X, MARGIN, FUN, ..., simplify = TRUE)

Where:

  • X is an array
  • MARGIN is an integer vector indicating which margins should be retained
  • FUN is a function to be applied
  • ... is for other arguments to be passed to FUN

So, let’s create a 20x10 matrix, containing normal random variables:

t <- matrix(rnorm(200), 20, 10)

Now, let’s use apply to calculate the mean of each column of thr matrix:

apply(t, 2, mean)
 [1]  0.432418616  0.129212729  0.222425658  0.003252688 -0.293432859
 [6] -0.160915511 -0.188911594  0.011591248 -0.028383461  0.174617879

In this case, apply returns a vector of length 10 containing the mean of each column of the matrix.

Similarly, let’s calculate the sum of all the rows:

apply(t, 1, sum)
 [1] -0.4115897  0.3777743 -0.1052147  3.7735983  2.6486216 -2.4123001
 [7] -0.7180522  2.7999021 -2.0273366  0.7446420  1.8495905  3.2011752
[13] -6.4587513  6.0925203  1.1031986  0.4062273 -1.0372624 -2.6341064
[19] -4.1335815  2.9784527

col/row Sums and Means

For simple operations, like calculating the sum, or calculating the mean or the sum of a column or a row, there are special functions that are highly optimized to do this very quickly.

  • rowSums = apply(x, 1, sum)
  • rowMeans = apply(x, 1, mean)
  • colSums = apply(x, 2, sum)
  • colMeans = apply(x, 2, mean)

These shorcuts are much faster, but one only notice when working with large matrices.

[2,] -0.0189741  0.3592545

mapply

mapply is a multivariate version of apply which applies a function in parallel over a set of arguments.

Syntax

str(mapply)
function (FUN, ..., MoreArgs = NULL, SIMPLIFY = TRUE, USE.NAMES = TRUE)

Where:

  • FUN is a function to apply
  • ... contains arguments to apply over
  • MoreArgs is list of other arguments for FUN
  • SIMPLIFY indicates whether the result should be simplified

The following would be tedious to type:

list(rep(1, 4), rep(2, 3), rep(3, 2), rep(4, 1))
[[1]]
[1] 1 1 1 1

[[2]]
[1] 2 2 2

[[3]]
[1] 3 3

[[4]]
[1] 4

Instead, we could do:

mapply(rep, 1:4, 4:1)
[[1]]
[1] 1 1 1 1

[[2]]
[1] 2 2 2

[[3]]
[1] 3 3

[[4]]
[1] 4

Example: Vectorizing a function

With mapply we could vectorize a function that doesn’t work with vectors.

noise <- function(n, mean, sd) rnorm(n, mean, sd)

So calling noise with a single set of arguments, we get 5 random numbers with a mean of 1 and a standard deviation of 2.

noise(5, 1, 2)
[1] -0.2183343 -1.6513177  4.2968177  0.6169264  3.9232039

However, if we pass vectors, we don’t get the expected behavior, i.e., one random normal with mean one, two random normals with mean 2, etc.

noise(1:5, 1:5, 2)
[1]  2.5398927  2.0219263 -0.9786324  3.9197752  4.0178453

Using mapply however, gets us the expected result.

mapply(noise, 1:5, 1:5, 2)
[[1]]
[1] 0.8609015

[[2]]
[1] -0.4187326  1.4531679

[[3]]
[1] 3.4990433 4.3118648 0.6801589

[[4]]
[1] 4.413957 4.116003 4.426201 5.091021

[[5]]
[1] 1.105274 8.056318 4.888880 1.657919 8.874558

tapply

tapply is used to apply a function over the subsets of a vector.

Syntax

str(tapply)
function (X, INDEX, FUN = NULL, ..., default = NA, simplify = TRUE)

Where:

  • X is a vector
  • INDEX is a factor or a list of factors (otherwise, they are coerced to factors)
  • FUN is a function to be applied
  • ... contains others args to be passed to FUN
  • simplify indicates whether to simplify the result

Example

Let’s simulate a vector of ten normal random variables, ten uniform random variables, and ten normals with a mean of 1.

w <- c(rnorm(10), runif(10), rnorm(10, 1))

We can think of vector w as having three groups.

Now, let’s create a factor variable f, with three levels repeated 10 times:

f <- gl(3, 10)

So, by printing f, we can see ten ones, ten twos, and ten threes, indicating in which group each observation is in.

Then, we can use tapply to get the mean of each group of numbers in w.

tapply(w, f, mean)
         1          2          3 
-0.5113314  0.5328757  0.9765954
